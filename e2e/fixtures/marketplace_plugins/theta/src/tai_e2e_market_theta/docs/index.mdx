# e2e-theta fixture plugin

This landing page ships so the fixture carries the mandatory docs index the
marketplace ingest requires for every published version. It documents nothing
beyond the fixture's role in the tai42 e2e suite: a router whose declared route
shape-collides with the epsilon fixture until its mount base is remapped.
